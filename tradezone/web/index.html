🏦 Connect your real-money account

Where do you keep your money?
TradeZone trades real money in your Uphold account - crypto and meme coins, straight from your USD balance. Connecting takes a few minutes:
  1. Put the money the bots may use (e.g. $50) in your Uphold USD balance.
  2. On the computer running TradeZone, run python -m tradezone uphold-token and log in to Uphold when asked (your password goes only to Uphold and isn't saved).
  3. Copy the long token it prints and paste it below.
Open Uphold ↗
Heads-up: Uphold's price includes a spread of about 1% each way, so the bots skip tiny trades that couldn't beat it. Practice trades charge the same cost, so practice results match real ones.
TradeZone trades real money through Alpaca, a regulated broker. Connecting takes about 2 minutes:
  1. Open alpaca.markets and log in (or sign up - it's free).
  2. Make sure you're in your Live account, not "Paper".
  3. On the home page find API Keys and tap Generate New Keys.
  4. Copy the two codes and paste them below (copying both at once works too).
Open Alpaca ↗
The bots can buy, sell and take profits on Kraken. They can never withdraw money or crypto.
  1. Open kraken.com → log in → Settings → API → Create API key.
  2. Turn ON only: Query Funds, Query Open Orders & Trades, Query Closed Orders & Trades, Create & Modify Orders, Cancel/Close Orders.
  3. Leave OFF: Withdraw Funds, Deposit Funds and Earn. (TradeZone checks this and refuses a key that can withdraw.)
  4. Tap Generate key, then copy the API Key and the Private Key below.
Open Kraken API settings ↗
🛡️ Coins you already hold on Kraken are left alone - the bots only trade what they buy themselves.
Your keys stay on your own server and are never shown again. TradeZone keeps using practice money until you choose "Use real money".
